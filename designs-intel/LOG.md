## [2026-05-25] RULARE 2 — Delta real, 5 adaugiri

**Surse verificate:** socialinsider.io, buffer.com (52M+ posts), trymypost.com, carouselli.com, storrito.com, hootsuite.com, sproutsocial.com, meetedgar.com, heropost.io, attentioninsight.com — toate 2026-Q1/Q2.
**Respins inainte de includere:** studiul Pantone/Fohr/Carlsbad citat ca "2026" = studiu din 2019 — halucinatie sursa, exclus.

**Delta adaugat:**

G1 (paleta):
- Paleta 2026 cu denumiri specifice: Cloud Dancer white (baza) + accent unic: Transformative Teal / Electric Fuchsia / Blue Aura / Amber Haze / Jelly Mint
- Principiu transferabil: cu cat fundal mai neutru, cu atat accentul sare mai tare — nu alege 2 accente

G2 (tipografie):
- Regula practica noua: text/hook in treimea superioara a imaginii = vizibil in crop 1:1 din feed fara click. Daca nu se citeste in thumbnail, stop-rate-ul e zero

G3 (layout/carusel):
- Cifre reale Q1 2026, sample 52M+ posts (buffer.com): carousel 0.52%, Reels 0.50%, single image 0.35%
- 5-7 slide-uri = 3.4x saves + 2.1x shares vs. imagine statica (trymypost.com)
- 8-10 slide-uri depasesc 2% engagement rate — umple caruselul daca ai continut educational
- Mixed-format (img + un slide video) = +29% fata de image-only
- Views = metrica afisata; saves + shares = metrica de distributie reala

G4 (element neasteptat):
- Originalitate = semnal de ranking direct 2026; continut reciclat/TikTok-watermarked e de-rankat explicit — elementul original surprinzator e si algoritmic, nu doar vizual

**Goluri ramase:**

## [2026-05-22] PRIMA RULARE — Delta complet (punct 0)

**Stare anterioara:** repo gol, niciun fisier anterior.
**Surse verificate:** 20+ URL-uri cautate; WebFetch blocat 403 pe toate sursele externe (politica retea container); date extrase din snippets cautare Google.
**Acoperire data:** surse datate 2026-01 pana 2026-05 (in fereastra 3 luni).

**Delta adaugat:**

G1 (paleta/contrast):
- Luminance contrast = predictor principal stop-rate, +40% retentie la varianta mare frame 1
- Contrast ratio 4.5:1 minim pentru lizibilitate
- Color vs. B&W: +24% likes, +46% comentarii
- Paleta 2026: terracotta + warm stone + accent safran/periwinkle
- Formula: crem + forest-green + burnt orange DOAR accent
- Sage verde evolueaza spre khaki/dusty

G2 (tipografie/ierarhie):
- Text overlay = +50% engagement vs. imagini fara text
- Headline: 5-8 cuvinte, specifice, curiosity gap
- Weight contrast: bold headline + thin body > size contrast singur
- Font "Poster" (heavy serif) in trend 2026
- Diagonal 15-45 grade = miscare in static
- Unicode custom = +22% CTR (Digital Aesthetics Institute 2025)

G3 (layout/compozitie):
- Carusel = 2.14x engagement vs. single post
- Algoritm 2026: dwell time + swipe velocity > likes
- Slide 1: opreste / promite / curiosity gap simultan
- Ritm vizual: acelasi layout, accent variabil per slide
- Bleeding edge element obliga swipe-ul

G4 (element neasteptat):
- Chromatic contrast = pre-atentiv, cel mai rapid scroll-stopper
- Pattern interrupt top: out-of-palette accent, asimetrie, face direct, scale shock
- "Dopamine pop" = 1 element saturat in paleta muta > intreaga imagine saturata
- Regula: commit full sau deloc

**Goluri ramase:** nicio data de save-rate reala (%) pe tipuri de design specifice; lipsesc studii cu sample size cunoscut; lipseste analiza specifica pe estetica i-vory (stil actual necunoscut agentului).
